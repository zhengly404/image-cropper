图片裁剪工具 — 项目说明书
==============================

一、项目概述
-----------
这是一个基于网页的图片裁剪工具，用户可以通过浏览器上传图片，
然后使用多种方式裁剪图片，最后打包下载裁剪后的图片。

二、技术组成
-----------
1. 后端框架：Flask（Python 网页框架）
2. 图片处理：Pillow / PIL（Python 图片处理库）
3. 前端页面：HTML + CSS + JavaScript（画布绘制使用 Canvas）
4. 依赖版本：Flask 3.0.0、Pillow 10.1.0、Werkzeug 3.0.1

四、工作流程
-----------
1. 用户打开网页，上传一张图片
2. 图片显示在画布上，用户选择裁剪方式
3. 前端（浏览器）计算裁剪区域，发送裁剪请求到后端
4. 后端（服务器）使用对应的裁剪方式处理图片
5. 裁剪后的图片显示在结果页面，用户可以单独下载或打包下载


五、裁剪方式
-----------
本工具支持两大类裁剪方式：

1. 网格裁剪
   把图片等分成若干行和列，切成多个小方块。
   例如：3×3 切成 9 张，4×4 切成 16 张。
   支持 2×2、3×2、3×3、4×4、5×5 等预设，也可自由设置行列数。

2. 自由裁剪
   a) 矩形裁剪：在图片上拖拽出矩形区域进行裁剪
   b) 形状裁剪：裁剪成特定形状，包括：
      - 圆形
      - 心形
      - 星形（可调整角数）
      - 多边形（可调整边数）
      - 三角形
      - 菱形
   形状裁剪后背景透明，保存为 PNG 格式。


六、页面功能
-----------
1. 主页面（裁剪页）
   - 上传图片（点击或拖拽）
   - 左侧工具栏：设置网格行列数、选择裁剪形状、操作提示
   - 中间画布：显示图片、裁剪框（可拖拽移动和缩放）
   - 右侧裁剪列表：显示所有裁剪区域的信息
   - 底部控制：缩放画布、重置视图
   - 结果页面：预览裁剪结果、单独下载或打包下载 ZIP

2. 图片库页面
   - 浏览所有已上传和裁剪的图片
   - 搜索图片名称
   - 按时间、名称、大小排序
   - 查看大图（支持缩放和拖拽）
   - 删除单张图片或清空全部


七、运行方法
-----------
1. 安装依赖：
   pip install -r requirements.txt

2. 启动服务器：
   python app.py

3. 在浏览器打开：
   http://127.0.0.1:5000

4. 停止服务器：
   在终端按 Ctrl+C
